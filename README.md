# PSXPlayer

Yet another PSF music player. It has a QT UI, and some features I wanted from a PSF player like
tracking forward and backward, changing playback speed, note identification, and the ability to mute
individual channels.

Additionally, it has the capability of "de-scramble" music voices in some games that didn't play
individual voices in dedicated hardware channels. So far, it only has suport to de-scramble some
squaresoft games.

The player is based on the emulator [libupse](https://github.com/kode54/libupse), with some minor
modifications to accomodate for the features I wanted.
